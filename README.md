# agents

Shared config for all my coding agents in one repo: a global rules file and a set of skills, both under `agents/`.

## Install

Paste this into your coding agent:

> Read https://github.com/bradennss/agents/blob/main/INSTALL.md and follow it.

It clones this repo and symlinks the global rules and skills into your agent's own global config, so the config loads on every start. Safe to run again.
